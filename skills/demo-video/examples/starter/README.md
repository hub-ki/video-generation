# Starter files

Copy these into a new video project next to `index.html`:

```
PLAN.md        the shape — approved before anything is captured
SCRIPT.md      every word — approved with it
narration.mjs  the spoken track, only for a narrated guide
brand.json     copy ../../assets/brand.example.json, or generate it with extract-brand.mjs
```

`PLAN.md` and `SCRIPT.md` are written by the `video-plan` skill. `TIMELINE.md` is generated by
`audit-composition.mjs --timeline` and is never edited by hand.
